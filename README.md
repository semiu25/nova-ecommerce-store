# NOVA — E-commerce Storefront

A responsive frontend portfolio project built with HTML, CSS and vanilla JavaScript.

## Features
- Product catalogue with category navigation
- Live search and sorting by price/rating
- Filters for price, availability and customer rating
- Product detail modal
- Wishlist saved in localStorage
- Shopping cart with quantity controls and subtotal
- Free-shipping progress indicator
- Simulated checkout form and order confirmation
- Newsletter signup interaction (demo only)
- Responsive mobile and desktop layouts

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required. Product photos load from Unsplash.

## Important
Frontend-only demonstration: no payment provider, backend, database, inventory service or email platform is connected. Checkout and newsletter signup are simulated. Do not enter real payment information.
